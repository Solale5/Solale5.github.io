Privacy policy

Effective September 10, 2026. This policy covers the Tab Shelf Chrome extension, published by Solomon Alemu.

What the extension accesses

Tab Shelf reads open-tab metadata, including titles, full URLs, tab identifiers, window identifiers, last-activated timestamps, and state such as active, pinned, audio-playing, loading, private, and discarded. It uses this information to show and filter tabs, explain cleanup suggestions, protect tabs, and carry out your selected actions. Private tabs are excluded from the interface and archiving.

What stays on your device

Save & close stores selected titles, URLs, last-activated times, saved times, batch identifiers, tab identifiers and recovery status in Chrome’s local extension storage. Imported backups are stored there too. This storage is not Chrome sync storage. Just close does not create an archive record. No page contents, passwords, form text, screenshots, or navigation history are collected by the extension.

No developer transmission

Tab Shelf does not send tab metadata or saved links to Solomon Alemu or any server. It has no advertising, analytics, remote code, data sales, or background network requests. It does not use browsing information for creditworthiness or lending purposes. Opening a saved URL or clicking an external link navigates to that site, whose own privacy practices then apply.

Backups and deletion

Export creates a JSON file containing your saved titles, URLs and related metadata. Full URLs can contain private query parameters. You control where that file is kept or shared. Import reads only the backup file you choose. Saved records remain in the Chrome profile until extension storage is cleared or the extension is uninstalled. Exported files remain on your device until you delete them. This release does not offer selective archive deletion.

Permissions

The tabs permission allows the extension to read tab titles and URLs for listing and selected cleanup. The storage permission allows local archiving and recovery. The extension requests no host permissions and injects no scripts into websites.

This website and support

This project website is hosted separately on GitHub Pages; the hosting provider may process ordinary web requests under its own policies. The site adds no analytics. If you contact the developer through LinkedIn or GitHub, those services process the information you choose to share. Do not post private browsing information in public support requests.

Contact and updates

Contact Solomon Alemu on LinkedIn or use the project issue tracker. Changes to this policy will appear here with an updated effective date.
